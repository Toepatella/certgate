CertGate Explain

A safety gate sits in front of this computer model: it answers only when confident enough, and hands everything else to a person. Pick a case to see why it decided the way it did — and try changing the inputs yourself.
Read this first. This page describes the computer program, never the patient. "What would need to change for the computer to answer" is a fact about how the program decides — not medical advice, not a treatment suggestion, and not something anyone could do to a patient. A case flipped by the smallest change is answered with the lowest confidence the program is allowed. The safety promise is about average mistakes across many hospitals, not any one case here. Data shown: . Read this first. Every interactive control asks a score-space question of the gate: what would the model's inputs need to be for this case to clear the answering bar. Not causal claims, not treatment suggestions, not clinically achievable actions. The minimal flip clears the bar by the documented 1e-9 logit headroom — the weakest answerable answer. The certificate is a site-population-average guarantee over answered cases: no individual record carries a certified property. Cohort: .

How to read this page (30 seconds)
  1. Pick a case on the left. Green = the program answered; red = it wasn't sure enough and handed the case to a person.
  2. The meter shows how sure it was. It must clear the dark line.
  3. The bars show what pushed confidence up or down. When pushes and pulls cancel out, it hands the case over.
  4. Try the controls — change a value and watch it re-decide. The red button puts everything back.
  5. Values marked not recorded were never measured for this patient; the number beside them is a stand-in the model fills in.
