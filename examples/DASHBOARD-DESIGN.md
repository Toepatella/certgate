# Design — CertGate Explain dashboard

Describes the page generated by `examples/explain_dashboard.py`. The design
itself lives in that file's `_HTML_TEMPLATE` literal; the direction contract is
the first HTML comment in its `<body>`. Ground truth is the built page — this
file describes it, it does not specify it.

Recorded from the built world after the 2026-07-31 redesign (impeccable
new-work flow, Operate mode, concept-roll seed `ef24fd77`, assigned direction:
candidate 7 — **bench instrument + calibration paperwork**), which was carried
out in the `certgate-dashboard-design/` sandbox: the same template rendered
against a synthetic non-clinical fixture, so the design could be worked on
without the restricted extract. The five degraded variants named under
Invariants are that sandbox's `variants/`.

## The world

A certified selective classifier explained as the measuring instrument it is.
Every quantity sits on a graduated scale with its red-line, its band, and its
caveat. The page refuses the analytics-dashboard arrangement — no KPI hero
tiles, no card grids, no decorative charts, no glassmorphism, no shadows.
Recognizable with all content removed: ivory plates on a cool bench-gray
ground, hairline rules, engraved-caps section labels, tick scales, the
red-line, the needle.

Semantics are load-bearing: green/red never decorate; cobalt never encodes
answered/declined; amber marks imputed/caveated values only. Dark mode is
composed (night panel), not inverted. Certificate plates: `--certbg/--certline/
--certink` (calibration plate), `--uncbg/--uncline/--uncink` (out-of-cal tag).

## Type

One family: the system UI stack (deliberate — the artifact is one offline HTML
file inside a Python string; webfonts are impossible, and Operate permits the
workhorse stack). Hierarchy is role discipline, not family contrast:

- Masthead h1 21px/650 (adv 19px) with the drawn gauge mark.
- Section labels (h2): 12.5px, 650, uppercase, +.07em, with a trailing
  hairline graduation rule (`h2::after`).
- Body: 16.5px simple / 14px adv — the registers must FEEL different.
- Data: 13.5px tables/inputs; 12.5px notes/controls; 12px floor (tick
  numerals, tags, statusbar). `tabular-nums` on every figure.

## Signature components

- **Meter** (`.meter`): graduated tick rail (major/minor), green band from τ*,
  red-line with flag label, 2px ink needle with pointer head. The needle's
  240ms `cubic-bezier(.22,.68,.36,1.04)` settle is the page's ONE authored
  motion; everything else is quick state feedback, and reduced-motion kills all.
- **Distribution** (`.hist`): same grammar — baseline rule, band, red-line
  flag, ticked axis (`.haxis`).
- **Slider rails** (`.sldw`/`.srail`/`.smark`): every what-if slider runs on a
  hairline tick rail with a notch at the recorded value; the threshold
  explorer's notch is the deployed τ* in red-line color. Inputs stay native
  (no reinvented affordances) — the rail is the world, the control is the OS.
- **Calibration plate / out-of-cal tag** (`.certb`): drawn seal or warning
  triangle; the UNCERTIFIED tag is the page's one red flood.
- **NOTE plate** (`.caveat`): engraved "READ THIS FIRST" lead; plain plate,
  no side stripe, no alarm styling — candor is the register.
- **Bench mat** (`.fence`): dashed border + amber ground = outside the
  certified path (threshold explorer).
- **Icons**: authored inline SVG only, 1.5–1.8px stroke, currentColor (gauge
  mark, seal, warning, moon, printer, reset). No emoji, no glyph icons.

## Layout

4px-base rhythm; plates 6px radius, 18/22px padding (simple 20/24). Masthead
closed by a 2px ink rule. Rail (`.side` 292px) + bench (`.detail`) as flex;
structural responsive collapse at 720px (rail full-width, srow grid to
`1fr auto`, strip rules dropped). Tables: engraved-caps headers over a 1.5px
rule, hairline rows, `.tblwrap` scroll containers — the body never scrolls
horizontally. Print hides the interactive chrome and keeps the plates.

## Invariants (do not regress)

- Two registers, one file: `body.simple`/`body.adv` with `.simponly`/`.advonly`
  — losing those two CSS rules renders both registers at once.
- `const DATA = ` line untouched; one `__PAYLOAD__`; no `"""`; no trailing
  backslash; LF; starts `<!DOCTYPE html>`.
- A11y floor: 4.5:1 body text, 3:1 controls/graphics, 2.5px cobalt
  focus-visible ring, 44px touch targets, Enter/Space on role=button spans,
  aria-pressed on toggles, color never the only channel.
- All five degraded variants must lay out cleanly from the same template.
- Edge headless clamps to ~492px window width — capture mobile evidence in a
  live browser.
